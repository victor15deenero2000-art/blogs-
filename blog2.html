Representación de Grafos

🟣 Por Ana G. · 4 Dic 2024

1. Lista de Adyacencia

Esta representación almacena para cada nodo el conjunto de vecinos a los que está conectado. Es ideal para modelar redes con pocas conexiones en comparación con la cantidad total de nodos, ya que solo se guarda la información estrictamente necesaria. 

A → B, D
B → A, C
C → B
D → A

Ventajas

  • Excelente eficiencia en memoria para grafos grandes y dispersos.
  • Facilita recorrer nodos vecinos sin procesar toda la estructura.

Desventajas

  • El acceso directo para verificar si dos nodos están conectados puede ser más lento.

2. Matriz de Adyacencia

Representa las conexiones mediante una matriz cuadrada donde cada celda [i][j] indica con un 1 o 0 si existe una arista. Es una forma compacta y uniforme, especialmente útil cuando el grafo presenta muchas conexiones. 

    A B C D
A | 0 1 0 1
B | 1 0 1 0
C | 0 1 0 0
D | 1 0 0 0

Ventajas

  • Permite verificar relaciones entre nodos en tiempo constante O(1).
  • Adecuada para grafos densos donde la mayoría de nodos están conectados.

Desventajas

  • El consumo de memoria crece rápidamente con el número de nodos.

3. Lista de Aristas

Consiste en registrar únicamente las aristas existentes, es decir, cada par de nodos que mantiene una conexión. Es una forma clara y directa de describir relaciones, especialmente útil para algoritmos que trabajan sobre listas de conexiones. 

(A, B)
(A, D)
(B, C)
